1. COMO EXECUTAR O PROGRAMA
---------------------------
Requisito: Python 3 instalado.

No terminal, dentro da pasta do projeto:

    python base.py

(em alguns sistemas o comando e' "python3 base.py")

Ao iniciar, o programa pergunta como popular a lista de processos:

    Sera aleatorio?:

  - digite 1 para sortear os atributos aleatoriamente (random.randint)
  - digite 0 para digitar os atributos pelo teclado

No modo manual sao pedidos, para cada processo e nesta ordem:
tempo de execucao, tempo de chegada e prioridade.

Em seguida e' exibido o menu:

    1 = FCFS                        (entrega 1)
    2 = SJF Preemptivo              (entrega 2)  <- nesta versao
    3 = SJF Nao Preemptivo          (entrega 2)  <- nesta versao
    4 = Prioridade Preemptivo       (entrega 3)
    5 = Prioridade Nao Preemptivo   (entrega 3)
    6 = Round-Robin                 (entrega 4)
    7 = Imprime a lista de processos
    8 = Popula a lista de processos novamente
    9 = Sair

As opcoes 4 a 6 existem no menu porque fazem parte do codigo-base, mas suas
funcoes ainda sao os esqueletos originais.

Cada funcao copia as listas com list() antes de simular, sem destruir a
entrada. Assim a mesma lista pode ser rodada no FCFS, no SJF nao preemptivo e
no SJF preemptivo, comparando o tempo medio de espera de cada politica.


2. O QUE O PROGRAMA IMPRIME
---------------------------
Para cada execucao:

  - o historico de execucao: uma linha por instante de tempo, no formato
    tempo[i]: processo[p] restante=r
    (ou "tempo[i]: CPU ociosa" no SJF, se nenhum processo chegou ainda);
  - o tempo de espera de cada processo;
  - o tempo medio de espera (soma das esperas dividida por n_processos).


3. EXEMPLO COMPARATIVO (modo manual)
------------------------------------
    Processo   tempo_execucao   tempo_chegada
       0             8                1
       1             4                2
       2             2                3

FCFS (opcao 1) - ordem da lista, ignora a chegada:
    P0 em 1..8, P1 em 9..12, P2 em 13..14
    esperas: 0, 8, 12          media = 6.67

SJF nao preemptivo (opcao 3):
    Em t=1 so P0 chegou, entao ele roda ate o fim (1..8).
    Em t=9 estao prontos P1 (4) e P2 (2): vai o mais curto, P2 (9..10).
    Depois P1 (11..14).
    esperas: 0, 9, 6           media = 5.0

SJF preemptivo (opcao 2):
    t=1  P0 roda (restante 8)
    t=2  chega P1 (4 < 7): P1 toma a CPU
    t=3  chega P2 (2 < 3): P2 toma a CPU, roda em 3..4
    t=5  P1 volta (5..7), depois P0 termina (8..14)
    esperas: 6, 2, 0           media = 2.67

O preemptivo tem a menor media: e' o que se espera do SJF, que e' otimo para
o tempo medio de espera.

5. CONVENCOES ADOTADAS
----------------------
  - Os processos sao representados por listas paralelas indexadas pelo numero
    do processo: tempo_execucao, tempo_chegada, prioridade, tempo_restante e
    tempo_espera.
  - FCFS: nao usa o tempo de chegada (conforme o enunciado). A decisao fica no
    trecho em que o processo chega ao ultimo instante (tempo_restante == 1) e
    a CPU passa para processo_em_execucao + 1, sem preempcao.
  - SJF: um processo so pode ser escolhido a partir do instante em que chega
    (tempo_chegada <= i). Entre os prontos, vai o de menor tempo restante; em
    caso de empate, o que chegou primeiro e, persistindo, o de menor indice.
  - SJF nao preemptivo: a escolha so e' refeita quando a CPU fica livre.
  - SJF preemptivo (SRTF): a escolha e' refeita a cada instante.
  - Espera no SJF: a cada instante, soma-se 1 para cada processo que ja
    chegou, ainda nao terminou e nao esta na CPU (funcao contabiliza_espera).
  - Se nenhum processo chegou ainda, o instante e' impresso como CPU ociosa.
